# autoconfig
### automatic configuration for Ubuntu 16.04 LTS, Ubuntu 20.04 LTS, Ubuntu 24.04 LTS, and Raspbian 10 buster.
* For vps on OCI/GCP/AWS, it is configured to run nginx, hallelujah, shellinabox, v2ray, jupyter-notebook and mariadb, compaitible with ubuntu 20.04/22.04/24.04 LTS.
* For raspberry model 4b, it is preconfiged and initialized with Chinese input method, python virtual env, compatible with raspberry pi os 64-bit bullseye.
* Additionally, bigdata config, chatgpt, data analysis, code diff stats and directory batch operations are also provided as utilities.
* cheatsheet about mysql and python are also available.
